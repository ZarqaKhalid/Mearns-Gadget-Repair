Mearns Gadget Repair Centre - Official Website
A modern, fully responsive static website for Mearns Gadget Repair Centre, a local electronics and gadget repair business based in Newton Mearns, Glasgow. This project includes all front-end pages, forms, and UI components required to run the website.

🌐 Live Pages Included
This repository contains the following static HTML pages:

index.html: Homepage with hero section, services overview, interactive tabs, customer reviews, and a booking form.
about.html: About Us page detailing the company story, values, and workshop information.
services.html: Detailed breakdown of all repair services offered (Mobile, Laptop, MacBook, Console, GHD, etc.).
book-repair.html: The "Fix Now" page featuring a 3-step guide and the comprehensive device booking/quotation form.
contact.html: Contact information, Google Maps integration, social links, and a direct messaging form.
blog.html: Blog and repair guides grid showcasing recent articles and tech tips.
✨ Key Features
Responsive Design: Optimized for mobile, tablet, and desktop viewing.
Modern UI/UX: Glassmorphism effects, gradient overlays, and glowing hero sections.
Interactive Components:
Mobile hamburger menu.
Dropdown navigation for repair categories.
Tabbed interface on the homepage for exploring device fixes.
Floating WhatsApp contact button.
Drag-and-drop file upload zone in booking forms.
Confirmation modal popups upon form submission.
SEO Optimized: Includes meta descriptions, semantic HTML, and alt tags.
🛠️ Tech Stack
HTML5: Semantic markup.
CSS3: Custom stylesheets using CSS variables for easy theming (css/style.css).
JavaScript (Vanilla): For interactive elements like the mobile menu and form UI (js/main.js).
Font Awesome 6.5.1: For icons (loaded via CDN).
Google Maps API: Embedded iframe for location.
